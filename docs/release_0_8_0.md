# TGLC 0.8.0 release preparation

Version 0.8.0 delivers corrected SPOC extraction and robustness improvements.
It retains the public single-target workflow and the existing weighting defaults
(power 1.4, edge_compression 1e-4). New products identify the software as
`TGLCVER=0.8.0` and processing convention as `PROCVER=spoc-0.8.0`.
Publication status and the final checks are tracked below; a version change in
this checkout does not by itself mean that PyPI or GitHub artifacts are published.

## Changes

- Correct detector-pixel/ePSF interpolation in fitting and target rendering;
  center the edge-regularization grid consistently.
- Exclude saturation, missing/zero-weight pixels, and supplied masks from fits.
  Use rank-aware solving and preserve failed cadences as missing with flags.
- Propagate Gaia positions to the observation epoch, retain contributing stars
  outside the cutout, and preserve unknown or ambiguous crossmatches as unknown.
- Save signed raw aperture/PSF flux, separate additive offsets, a full-support
  aperture fraction, 32-bit flags, and explicit unknown cadence identifiers.
- Validate source/ePSF caches and record fit configuration/provenance in outputs.
- Accept integer/string TIC IDs and filesystem paths, return generated FITS
  paths, update plotting, and consolidate packaging, documentation, and tests.

## Migration from 0.7.x and preparation builds

- Use Python 3.10–3.12. Install the public and MIT QLP packages into different
  environments because both distributions/imports are named `tglc`.
- New light curves live under `lc/SPOC/` or `lc/TICA/`, with camera/CCD
  subdirectories for the full-frame workflow. Use the paths returned by
  `tglc_lc`, or update scripts that assumed `lc/*.fits`.
- Existing light curves remain separate and are not regenerated by installation.
  Let incompatible source caches be rebuilt. Legacy `.npy` ePSF caches and
  caches from the preparation processing convention are not reused; new `.npz`
  files contain input/configuration fingerprints. Reserve space/time for refits.
- The six flux columns have different meanings. `aperture_flux_raw` is the
  decontaminated 3x3 sum and `psf_flux_raw` is the fitted amplitude, in e-/s,
  before catalog offsets or detrending. They are not untouched detector pixels.
  Existing columns obey `aperture_flux = (aperture_flux_raw - LOC_BG) / PORTION`
  and `psf_flux = psf_flux_raw - PSF_BG`. The `cal_*` columns additionally apply
  normalization and detrending. Read the headers and the usage reference.
- `TESS_flags` and `TGLC_flags` are 32-bit integers. Unknown cadence IDs use -1
  with FITS null metadata. Do not treat missing/flagged measurements as zeros.

## Evidence and limits

The assembled correction implementation passed 105 offline tests with one
explicit small-field stress-case expected failure. Its preparation wheel/sdist
and installed-wheel tests passed. Real-signal comparisons cover three planet
sectors and a known stellar eclipse in two sectors, alongside source/cache/FITS
checks. These are evidence for the correction implementation; the final 0.8.0
artifact and platform checks remain separate tasks below.

PSF reference residuals improved in the small real-signal cohort, but
catalog-normalized fractional amplitudes did not improve uniformly. Catalog
flux estimates and modeled aperture fractions can change transit/variability
amplitudes. Keep raw flux and the recorded offsets available for inspection and
custom calibration; do not describe 0.8.0 as a universal depth or absolute-flux
calibration. Header MAD values describe scatter, not propagated per-cadence errors.

The configurable saturation cutoff defaults to approximately 80000 e-/s with
one-pixel dilation. It protects fitting and flags affected target windows;
extended bleed trails can require additional masking. It does not establish
accurate saturated-target photometry. TICA remains experimental. SPOC times
retain their existing cutout-reference barycentric correction; precision timing
work should verify the remaining reference-to-target correction.

## Later work

Broader weighting/prior calibration, improved normalization, larger timing and
signal-recovery benchmarks, a paper, TICA expansion and experimental photometry
features belong to subsequent work. Perfect agreement with every SPOC amplitude
and removal of the sparse-field expected failure are not independent 0.8.0
requirements. The [1.0 roadmap](release_1_0_0.md) records that longer program.
